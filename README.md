# B3 Commerce International

Site de révision de la classe B3 Commerce International (INSEEC 2026/27) : synthèses de cours et quiz interactifs, triés par cours.

- `index.html` : accueil, liste des cours
- `international-marketing/` : International Marketing (L. Perier), synthèse + 74 QCM
- `strategie-entreprise/` : Stratégie d'entreprise (A.-L. Boncori), synthèse + 72 QCM
- `gestion-budgetaire/` : Gestion budgétaire, coûts partiels (D. Ngonga), synthèse + 27 QCM

Chaque dossier de cours contient `synthese.html` et `quiz.html` ; la banque de questions est dans la constante `BANK` du quiz.

Site statique, aucun build : déployable tel quel sur Vercel.
